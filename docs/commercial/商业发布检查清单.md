# 愈康云诊所商业发布检查清单

## A. 软件包

- [ ] 主程序 `package.json` 与 `desktop/package.json` 版本一致。
- [ ] 使用完整 `knowledge_index.db`，不是精简占位索引。
- [ ] Font Awesome、SheetJS、二维码全部本地化，页面无外部 CDN。
- [ ] 安装程序为 NSIS EXE，可选安装目录。
- [ ] 安装后能创建桌面和开始菜单快捷方式。
- [ ] 托盘可打开窗口、数据目录、备份目录和日志目录。
- [ ] 可自动选择端口，也可固定端口。
- [ ] 开机启动开关可用。
- [ ] 本地服务异常退出后能自动重启。
- [ ] 卸载后业务数据默认保留。

## B. 数据安全

- [ ] 安装包不包含 `clinic_database`。
- [ ] 安装包不包含 `device-key.dpapi`。
- [ ] 安装包不包含患者日志、备份和更新私钥。
- [ ] JSON 导出、导入和换机迁移已在干净环境验证。
- [ ] 同一台电脑快照恢复已验证。
- [ ] 文档明确说明不能直接复制 DPAPI 数据库。

## C. 更新与签名

- [ ] 版本号已提升。
- [ ] Authenticode 签名状态为 Valid。
- [ ] 时间戳服务器可用。
- [ ] 更新清单为 Ed25519 签名。
- [ ] 更新包 SHA-256 与清单一致。
- [ ] 只使用 HTTPS 下载地址。
- [ ] 在旧版安装环境完成一次升级。
- [ ] 能在升级失败时手动重新安装并保留数据。

## D. 发布材料

- [ ] 客户安装指南。
- [ ] 故障排查手册。
- [ ] 备份与换机迁移说明。
- [ ] 更新与版本发布说明。
- [ ] 第三方许可与临床声明。
- [ ] SHA256SUMS 校验文件。
- [ ] 发布说明和已知问题。
- [ ] 客服入口、响应时限和紧急联系人。

## E. 推广前不能忽略的边界

- [ ] 免费开源 MIT 许可只覆盖代码，不自动覆盖药典、图片、模型和第三方数据库。
- [ ] 本地版本默认面向局域网，不应对公网端口直出。
- [ ] 会话、限速、账号锁定、CSRF、审计和渗透测试范围需要按真实部署环境复核。
- [ ] 真实执业场景需要医疗机构批准和合规评估。
- [ ] 通用客户包不应内嵌同一套云端 Edge Token。
