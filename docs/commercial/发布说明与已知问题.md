# 愈康云诊所 v5.1.0 发布说明与已知问题

## 一、版本定位

`v5.1.0` 是 Windows x64 离线单机工程版本，安装后由 Electron 桌面壳启动本地服务，包含托盘、端口选择、开机启动、异常重启、备份恢复和签名更新校验能力。

当前源码与安装链路已具备商业化交付的大部分工程基础，但能否正式推广仍取决于代码签名、药典授权和干净虚拟机验收，不能只根据版本号判断。

## 二、本版已完成

- Windows NSIS EXE 安装程序，客户不需要解压 BAT，也不需要单独安装 Node.js。
- Font Awesome、SheetJS 和二维码生成依赖随安装包离线提供，不依赖外部 CDN。
- 默认优先使用 `3002` 端口，占用时自动向后选择；托盘菜单可改为自动或固定端口。
- 系统托盘常驻，主窗口关闭后服务继续运行。
- 支持开机启动开关。
- 本地服务异常退出后自动重启，失败时记录日志并通知。
- 数据默认保存在用户数据目录，卸载时默认不删除业务数据。
- 提供图形化备份、恢复和换机迁移能力。
- 支持 Ed25519 签名的静态 HTTPS 更新清单、SHA-256 下载校验和 Authenticode 安装包校验。
- 提供客户安装、故障排查、备份迁移、更新发布、许可和发布检查文档。
- 修复了通用 `/api/:collection` 路由抢占二维码接口导致二维码返回 401 的问题。
- 门诊患者列表支持删除未收费、未发药记录，并同步清理待收费和待发药数据。
- 已保存病历支持修改，并通过事务同步门诊、患者档案、收费单和药房待发药记录。
- 药房支持关键词搜索和六类药品分类筛选，新入库与 Excel 导入均强制分类。
- 收费支持实际收费、优惠减免、顾客付款、找零和调整原因，营收按实际收费入账。
- 源码单元测试基线更新为 35 / 35 通过。

## 三、当前已知阻断与风险

### 1. 代码签名

本机当前没有受信任 Windows 代码签名证书，已生成包默认标记为 `internal-preview-unsigned`，不能公开推广。

### 2. 药典与第三方授权

药典整理数据、第三方字体图标、表格库、二维码库、模型或其他内容各有授权边界。MIT 许可证只覆盖代码，不自动覆盖数据、商标、图片、模型和数据库。正式经营和对外服务前必须取得相应授权。

### 3. 干净虚拟机验收

当前尚未完成全新 Windows 10/11 x64 虚拟机的安装、升级、卸载、数据保留和防火墙访问验收。开发机测试不能替代多版本干净环境验收。

### 4. 安全边界

- 登录 Session 当前保存在内存中，应用重启后需要重新登录。
- `cors()` 当前为全局开放配置。
- 尚未实现登录限速、账号锁定和完整 CSRF 防护。
- 适合本机或可信局域网，不应直接映射公网。
- 真实诊疗场景仍需权限、账号、审计、备份恢复和所在地合规复核。

### 5. 自动更新

静态 HTTPS 更新通道需要为每个客户或发布渠道配置签名公钥和通道地址。通用客户包不能内置同一套云控制面 Token、mTLS 私钥或统一 Edge 密钥。

## 四、验收证据

当前工程验证包括：

- 源码单元测试通过。
- 业务流程回归测试通过。
- 完整知识库索引哈希和文件大小校验通过。
- 离线第三方资源、依赖、敏感文件清理检查通过。
- 打包运行时 HTTP 冒烟测试覆盖登录页、二维码、Font Awesome 和 SheetJS。

最终发布前仍需补充：

- 有效 Authenticode 签名截图或校验输出。
- 药典和第三方商业授权文件编号。
- 干净 Windows 虚拟机验收记录。
- 目标客户合同、隐私政策和售后支持信息。

## 五、升级与卸载

- 升级前先执行完整数据导出。
- 更新包必须先通过 Ed25519 清单签名、SHA-256 和 Authenticode 三重校验。
- 卸载默认保留 `%APPDATA%\YuKangClinic` 中的业务数据。
- 如果不再使用，必须在停用和备份确认后人工删除数据目录。
