# 愈康云诊所客户服务与支持信息

> 本文是商业发布模板。正式推广前，发布主体必须把“待填写”内容替换为真实、可追踪的客服入口，否则 `promotion_ready` 不应设置为 `true`。

## 一、发布主体

- 公司或个体经营者：待填写
- 统一社会信用代码或主体信息：待填写
- 客服电话：待填写
- 客服邮箱：待填写
- 企业微信或工单入口：待填写
- 服务时间：待填写
- 隐私政策地址：待填写
- 用户协议或授权协议：待填写

## 二、支持范围

建议在合同中明确：

- 安装、启动、登录和版本升级。
- 端口、托盘、开机启动和防火墙设置。
- 数据备份、恢复和换机迁移指导。
- 已知缺陷修复和版本更新说明。
- 不包含：客户电脑系统重装、非授权第三方软件、网络运营商故障、盗版系统、擅自修改程序或数据库导致的问题。

## 三、故障分级建议

以下时限只是内部工单规划建议，是否构成合同承诺由发布方与客户另行约定。

| 级别 | 场景示例 | 建议首次响应 |
| --- | --- | --- |
| P1 紧急 | 服务完全不可用、数据可能丢失、多个终端无法使用 | 2 小时内 |
| P2 高 | 核心流程不可用、备份或恢复异常 | 1 个工作日内 |
| P3 一般 | 局部功能异常、显示问题、使用咨询 | 2 个工作日内 |
| P4 建议 | 优化建议、文档问题、非阻塞需求 | 5 个工作日内 |

## 四、报障时必须提供

1. 产品版本，例如 `v5.1.0`。
2. 发布通道，例如 `internal-preview-unsigned` 或 `commercial-signed`。
3. 安装包文件名和 SHA-256。
4. Windows 版本和系统架构。
5. 问题发生时间、操作步骤和实际结果。
6. `desktop.log`、`clinic-server.log` 的相关片段。
7. 界面截图；如涉及患者信息，必须先打码或脱敏。

## 五、数据安全要求

- 客服不得要求客户通过公开群聊发送完整数据库、设备密钥、身份证、手机号或患者病历。
- 远程排查前必须获得客户书面或可追溯授权。
- 优先使用“完整数据导出”的脱敏副本，不得直接复制 DPAPI 绑定的数据库目录。
- 问题处理完毕后，应删除不再需要的临时日志和导出文件。

## 六、升级与回滚

- 每次发布必须提供版本号、发布说明、SHA-256、签名状态和已知问题。
- 重大升级前，要求客户先导出完整数据并确认备份可用。
- 升级失败时，优先使用已验证的上一版本安装包重新安装，再恢复完整数据。
- 不允许在未确认数据兼容性的情况下跨多个大版本直接升级。
