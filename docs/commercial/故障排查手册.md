# 愈康云诊所故障排查手册

## 1. 双击安装程序没有反应

1. 检查文件是否完整，确认文件名和版本一致。
2. 查看任务管理器是否有安装程序进程。
3. 右键安装包，选择“属性”，检查是否被 Windows 标记为“来自其他计算机的阻止”。如有，先点击“解除锁定”。
4. 如果仍然不能运行，获取 `%TEMP%` 中最近的安装日志，并联系发布方。

## 2. Windows SmartScreen 提示未知发布者

原因：安装包没有 Authenticode 代码签名，或证书链未受信任。
处理：不要在客户现场强行绕过并当作正式版发布。应使用受信任的代码签名证书重新构建和签名。内部测试可以选择“更多信息 → 仍要运行”，但要在验收记录中注明未签名状态。

## 3. 安装后程序没有出现

1. 在开始菜单搜索“YuKang Clinic”。
2. 查看右下角系统托盘，点击上箭头展开隐藏图标。
3. 如果托盘有图标但窗口不见了，双击托盘图标。
4. 如果程序启动后自动退出，打开日志目录查看：

```text
%APPDATA%\YuKangClinic\logs\desktop.log
%APPDATA%\YuKangClinic\logs\clinic-server.log
```

## 4. 端口被占用或自动换端口

桌面版会自动尝试 `3002` 到后续端口，并优先复用已经运行的愈康服务。
如果需要固定端口：

1. 右键托盘图标。
2. 选择“端口设置”。
3. 选择“固定 3002”或其他端口。
4. 程序会自动重启并保存设置。

如果指定端口仍被其他软件占用，托盘菜单会显示实际选择的端口，不要只看旧的快捷方式地址。

## 5. 浏览器打开空白页或图标、Excel、二维码异常

正常离线包必须具备以下文件：

```text
vendor\fontawesome\css\all.min.css
vendor\xlsx.full.min.js
vendor\qrcode
```

如果页面空白：

1. 打开“打开日志目录”，查看服务日志。
2. 将 `%APPDATA%\YuKangClinic\logs\clinic-server.log` 发给维护人员。
3. 检查杀毒软件是否删除了 `resources\clinic_system\vendor` 下的文件。
4. 重新安装完整 EXE，不要从旧 ZIP 中复制残缺目录覆盖。

## 6. 手机无法访问

1. 确认手机和电脑连接到同一个 Wi-Fi，且不是访客网络。
2. 在系统“设置”页核对局域网地址。
3. Windows 防火墙允许 `YuKangClinic.exe` 和 Node/Electron 服务通过“专用网络”。
4. 路由器不能开启“AP 隔离”。
5. 公司网络如果限制设备互访，需要让网络管理员放开同一子网访问。

## 7. 数据不见了

先不要删除、重装或复制数据库。检查：

1. 是否切换了 Windows 用户账号。数据目录按 Windows 用户隔离。
2. 是否更换了电脑或重装系统。DPAPI 密钥无法跨机器复制。
3. 设置页是否能看到历史备份。
4. 是否误用了旧的便携版目录。

恢复方式：优先在“设置 → 图形化备份与恢复”中恢复快照。跨机器恢复必须使用 JSON 导出文件。

## 8. 更新检查失败

1. 确认电脑能访问 HTTPS 更新地址。
2. 确认托盘菜单已导入 `update-config.json`。
3. 检查系统时间是否准确，证书验证和签名验证都依赖系统时间。
4. 查看日志中的“检查更新失败”。
5. 不要在诊所现场通过复制 EXE 到安装目录来热更新。必须使用签名安装包，让安装程序覆盖旧版本。

## 9. 服务连续重启失败

1. 托盘图标会出现异常通知。
2. 打开日志目录，保留最近的 `clinic-server.log`。
3. 暂停继续反复启动，避免破坏正在写入的数据。
4. 先复制 `%APPDATA%\YuKangClinic\clinic_database\backups` 到外置盘，再联系维护人员。

## 10. 必须遵守的安全边界

- 不要把本地端口映射到公网。
- 不要在公网服务器上直接运行同一个未加固的本地服务。
- 不要把 `clinic_database`、`device-key.dpapi`、日志和备份提交到 GitHub。
- 正式发布前必须完成 Authenticode 签名和 SHA-256 校验。
