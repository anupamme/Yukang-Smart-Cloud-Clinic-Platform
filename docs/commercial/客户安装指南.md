# 愈康云诊所 Windows 单机版客户安装指南

适用版本：v5.1.x
适用系统：Windows 10 / 11 x64
安装方式：EXE 安装程序，无需客户解压 BAT 或单独安装 Node.js。

## 一、安装前确认

1. 电脑至少有 2 GB 可用磁盘空间。
2. 安装时建议关闭会拦截未知程序的“自动沙箱”或安全软件弹窗，安装完成后再恢复。
3. 如果系统显示“Windows 已保护你的电脑”，说明当前安装包尚未完成 Authenticode 代码签名。请让发布方提供带签名的正式包；未签名包只适合内部验收，不适合直接大规模推广。
4. 诊所内如果有多台电脑或手机访问，需要保持主机开机，并允许 Windows 防火墙中的专用网络访问。

## 二、安装步骤

1. 双击 `YuKangClinic-Setup-5.1.x-x64.exe`。
2. 选择安装目录。默认安装到当前用户的程序目录，不需要管理员权限。
3. 等待安装完成，勾选“运行愈康云诊所”，点击完成。
4. 首次启动会初始化本机数据库并生成设备密钥，可能需要几秒到几十秒。
5. 程序关闭主窗口后会缩到系统托盘，本地服务继续运行。需要彻底退出时，右键托盘图标，选择“退出”。
6. 第一次使用请点击登录页的“注册”，按页面要求填写诊所和账号信息。

## 三、端口与多端访问

- 桌面版会自动选择可用端口。默认优先使用 `3002`，如果被占用会尝试后续端口。
- 托盘菜单“端口设置”可以改成自动选择或固定端口。
- 托盘菜单“打开愈康云诊所”会显示当前实际端口。
- 手机、平板访问时，必须与主机处于同一局域网，并允许 Windows 防火墙中的专用网络访问。
- 不要直接把端口映射到公网。本机版本没有针对公网暴露场景设计完整的限速、WAF 和多租户防护。

## 四、开机启动和后台运行

- 托盘菜单中的“开机启动”可以打开或关闭登录时自动启动。
- 主窗口关闭不会停止服务，程序缩到托盘继续运行。
- 服务异常退出时，桌面壳会自动重启本地服务。
- 多次重启失败时，请打开“打开日志目录”，把 `clinic-server.log` 和 `desktop.log` 发给维护人员。

## 五、数据位置

打包后的数据默认位于：

```text
%APPDATA%\YuKangClinic\clinic_database
```

日志位于：

```text
%APPDATA%\YuKangClinic\logs
```

桌面配置位于：

```text
%APPDATA%\YuKangClinic\desktop-config.json
%APPDATA%\YuKangClinic\update-config.json
```

不要直接把 `clinic_database` 复制到另一台电脑。数据库与 Windows DPAPI 设备密钥绑定，换机必须使用系统“设置 → 图形化备份与恢复 → 导出完整数据”。

## 六、首次使用检查

1. 工作台能正常打开，左上角显示版本号。
2. 设置页能看到“图形化备份与恢复”。
3. 手机连接同一 Wi-Fi 能打开局域网地址。
4. 后台备份目录中能看到当天快照。
5. 导出一次完整 JSON 数据，并确认文件可以打开。

## 七、卸载

1. 在 Windows“设置 → 应用 → 已安装的应用”中选择“YuKang Clinic”。
2. 点击卸载。
3. 卸载程序默认保留业务数据，防止误删患者资料。
4. 如果确定不再使用，需要人工删除 `%APPDATA%\YuKangClinic`。删除前必须先完成备份和停用确认。

## 八、上线前必须确认的边界

- 当前安装包如果没有有效 Authenticode 签名，不能视为可大规模分发的正式商业版。
- 药典数据的正式商业使用必须获得相应授权。
- 用于真实诊疗前，应由医疗机构完成部署验证、权限配置、备份恢复演练和所在地合规评估。
- 系统用于医生辅助管理，不替代执业医师诊断和处方决策。
